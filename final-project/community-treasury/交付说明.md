# 社区／开源项目共同资金管理：交付说明

本项目包含一个 ETH 资金池、三名固定负责人，以及两人分别批准后才能执行的付款流程。已有可运行合约、网页、自动化检查、最终英文报告和课堂展示材料。

## 在线演示与源码

- 私有网页：https://community-treasury-course-20261104.zxzccn.chatgpt.site
- 源码：https://github.com/zhuxuanze/ethereum-course/tree/codex/final-community-treasury/final-project/community-treasury
- GitHub 分支：`codex/final-community-treasury`。未合并到 main。
- 网页当前仅站点所有者可访问。老师或组员不能仅凭此链接访问；课堂可由所有者登录后演示。给组员的离线版本在交付包内。

网页托管已发布成功，但这不等同于把合约部署到以太坊主网或其他云区块链平台。网页的 Sandbox 在浏览器内实际运行编译后的 Solidity 合约，使用模拟账户和模拟 ETH；刷新或重置会新建本地链。

## 如何运行交付包

解压整个交付包后，进入 `project` 目录。在 macOS 双击 `启动本地演示.command`，保持终端窗口开启，访问 `http://127.0.0.1:8874`。需要系统中已有 Node.js 20+ 或 Python 3；交付包包含构建后的 `dist`，运行 Sandbox 无需安装项目依赖、钱包或访问 CDN。

如双击被系统限制，可在该目录执行：

```sh
node scripts/serve.mjs
```

或者：

```sh
python3 -m http.server 8874 --bind 127.0.0.1 --directory dist
```

若提示端口被占用，关闭上次演示的服务窗口后重试。按 Ctrl+C 停止服务。不要直接双击 HTML 文件；请通过上述本地 HTTP 地址打开。

## 建议课堂演示顺序

1. 点击 **Launch sandbox**，展示初始的 10 模拟 ETH。
2. 以 Manager A 提交一笔 0.25 ETH 的贡献者付款，说明提交本身不算批准。
3. Manager A 批准，展示 1/2 时仍不能执行。
4. 切换 Manager B 批准，再演示撤回批准使执行按钮禁用，然后重新批准。
5. 切换 Manager C 执行，展示余额 9.75 ETH、Paid 状态和实际本地交易回执。若事先充值 1 ETH，则余额是 10.75 ETH；报告截图采用后一种流程。
6. 切换 Supporter，展示其可以充值和查询，但不能提交、批准或执行付款。

详细英文讲稿、中文对照及操作提示在最终演示指南中。PPT 的每页备注也包含讲稿与操作说明。

## 正式提交前仍须补齐

- 组员英文姓名、真实分工，以及教授要求的本人签署声明；当前均未代填或代签。
- 向教授确认部署要求：两份材料分别写了至少一个、至少两个额外云区块链平台，另有以太坊主网要求。目前用户答复为“待定”，没有执行公网部署或支出真实资金。
- 确认后使用 `deploy/README.md` 和部署脚本，补齐所需网络的部署回执、浏览器连接验收及报告链接。
- 由小组确认最终内容，并在课程系统按实际截止时间提交。本次没有代提交 LMS 或向老师发信。

## 交付包结构

- `deliverables/`：Word 报告、可编辑 PPT、演示指南及相应 PDF。
- `proposal/`：此前的一页 W6 Proposal、中文对照、两分钟开题讲稿和要求整理。
- `project/`：源码、锁定依赖清单、测试、构建后的离线网页、部署脚本与证据。
- `MANIFEST.sha256`：文件清单与校验值。

源代码重建及测试命令见英文 README。运行交付包的离线网页不需要重建。
