# 社区／开源项目共同资金管理：交付说明

本项目包含一个 ETH 资金池、三名固定负责人，以及两人分别批准后才能执行的付款流程。已有可运行合约、网页、自动化检查、最终英文报告和课堂展示材料。

## 在线演示与源码

- [公开课堂演示](https://map-of-us-trial-d9fkeswkaf1e1376-1518430773.tcloudbaseapp.com/community-treasury/index.html)
- [公开项目源码](https://github.com/zhuxuanze/ethereum-course/tree/final-community-treasury/final-project/community-treasury)
- 网页托管在 CloudBase 的独立子目录。首次打开可能会出现腾讯云提示，倒计时后点击“确定访问”。选 Browser sandbox 后，演示资金和付款记录保存在当前浏览器的临时链（chain ID 1337）。
- 托管回执见 `evidence/cloudbase-deployment.json`。从公开地址验证付款的记录见 `evidence/cloudbase-browser-verification.json`。

## 如何运行交付包

解压整个交付包后，进入 `project` 目录。在 macOS 双击 `启动本地演示.command`，保持终端窗口开启，访问 `http://127.0.0.1:8874`。需要系统中已有 Node.js 20+ 或 Python 3；交付包包含构建后的 `dist`，运行 Sandbox 无需安装项目依赖、钱包或访问 CDN。

如双击被系统限制，可在该目录执行：

```sh
node scripts/serve.mjs
```

或者：

```sh
python3 -m http.server 8874 --bind 127.0.0.1 --directory dist
```

若提示端口被占用，关闭上次演示的服务窗口后重试。按 Ctrl+C 停止服务。不要直接双击 HTML 文件；请通过上述本地 HTTP 地址打开。

## 课堂演示顺序

1. 点 **Launch sandbox**，初始余额为 10 demo ETH。
2. 切换到 **Supporter**，存入 1 demo ETH，核对金库余额为 11。
3. 切到 **Manager A**，用预填地址提交 0.25 demo ETH 的付款，再点 **Approve**。一次批准后不能执行付款。
4. 切到 **Manager B**，批准同一笔申请，确认达到两票。
5. 切到 **Manager C** 执行，查看已付款标记、10.75 demo ETH 余额和交易回执。
